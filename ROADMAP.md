# Roadmap

This roadmap captures possible future work, not delivery commitments. Priorities
may change based on feedback and available time.

## Ideas

- Add automated tests for the server routes and core web interactions.
- Improve configuration and startup guidance for different operating systems.
- Replace manually maintained donation progress and donor information with a
  clear, maintainable update process.
- Continue improving accessibility and the experience on mobile screens.

Suggestions and discussion are welcome through GitHub issues.
