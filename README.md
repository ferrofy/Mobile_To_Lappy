# Requirements

- Python 3
- Both Device Over Local Network
- PyAutoGUI ( How To Download - Mentioned Below )

# Run on your computer

1. Open Terminal And Run Command Until Its Done...

```pip
pip install -r requirements.txt
```

2. After Click On File `Run.py`
3. You Will See Your Local (http + IP ) Something Like ---> http://10.204.1.113:7777 , This IP May Change In Your Case | Copy That IP And Open In Your Mobile's Browser
4. Done :)
5. To Test Add Any Text And Click On `Test Upload` The Text Should Be Visible In Terminal Of Your Computer
6. To Test Weather Its Writing Or Not Open Notepad And Click On Button `Write Text`
7. Once You Notted The IP You Can Close The `run.py` And You Can Click On `Run_BG.py` To Make It Work At Backgroud , So It Can't Be Closed By Any Other Software
