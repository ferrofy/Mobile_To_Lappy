# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in Mobile to Lappy,
please report it privately using one of the contact links below. Include a
description of the issue and steps to reproduce it. Please avoid sharing
potential vulnerabilities publicly until they have been reviewed.
